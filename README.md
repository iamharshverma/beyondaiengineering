## About the Book & Platform

*Beyond AI Engineering* is the category-defining career operating system for software engineers, AI professionals, students, and technical leaders navigating the age of autonomous AI agents.

### The Central Premise
> **AI can increasingly write the code. Your advantage moves to deciding what deserves to be built.**

When syntax generation drops toward zero marginal cost, the economic value of raw keystrokes collapses, while the premium on verified human judgment, systems architecture, and trust skyrockets.

## Core Intellectual Frameworks

1. **C.A.O. Framework**: Transitioning through the three evolutionary tiers of capability:
   - **Creator (Build)**: Implementation, experimentation, technical depth, prototyping.
   - **Architect (Design)**: Systems thinking, trade-offs, AI Product Sense, boundary invariants.
   - **Orchestrator (Lead)**: Multi-agent coordination, Agentic Diplomacy, governance, strategic trust.
2. **How → What**: Shifting focus from syntactic execution to high-leverage problem selection.
3. **The Trust Economy**: Why credible human judgment becomes the scarcest commodity when synthetic output becomes abundant.
4. **The Human API & Agentic Diplomacy**: Managing the boundary between human intent and autonomous agent execution.
5. **Digital Paper Trail & Proof of Work**: Demonstrating capability through visible, inspectable artifacts rather than claims.

- **Press & Media Kit**: High-res covers, author photography, standard bios (50, 100, comprehensive), and interview questions.

## Quick Start (Development)

This project is built with React 19, TypeScript, Vite, and Tailwind CSS v4.

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (runs on port 3000)
npm run dev

# 3. Build for production
npm run build
```
